# Changelog

## v0.1.1 — Pop UI refresh

- Rebuilt the renderer around the approved CASPULSE neon/pop mock direction.
- Replaced business-like labels with casual TwitCasting-oriented Japanese copy.
- Added the URL-first hero flow: **配信URLをぺたっ → のぞきにいく！**.
- Added a real live thumbnail area when TwitCasting returns a stream thumbnail.
- Added **見てる人 / コメ・分 / 勢い / いま** cards.
- Replaced the single-metric graph with a dual **いまの盛り上がり** viewers/comments wave.
- Added **コメントながれ**, **配信の空気**, **最近つないだ配信**, and a playful **わいわいログ** terminal.
- Reworded backend terminal events to feel like a stream companion instead of an operations console.
- Added the CASPULSE generated app icon for the in-app brand and Windows builds.
- Kept AI summaries clearly marked as future work; v0.1 atmosphere notes are rule-based from measured metrics only.

## v0.1.0

- Initial local MVP with TwitCasting OAuth, stable user-ID tracking, SQLite comment capture, TTS, and pulse metrics.

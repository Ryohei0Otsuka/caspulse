# CASPULSE Metrics v2

## 勢い

直近15秒のコメント量を、その前60秒のペースと比較します。

低コメント配信では1コメントだけで `+100%` などにならないよう、少量時は段階的な補正を入れています。

- 直前60秒が4コメント未満: 1件=`+25%`, 2件=`+50%`, 3件以上は緩やかに上昇
- 通常時: `直近15秒` と `前60秒÷4` を比較
- 表示範囲: `-100% ～ +400%`

## 盛り上がり

0〜100の観測スコアです。絶対的な人気度ではありません。

以下を飽和型のスコアとして合成します。

- コメント/分: 最大45
- 直近1分のユニーク投稿者: 最大20
- 視聴者の増加率: 最大15
- コメント勢い: 最大20

高トラフィックで簡単に満点へ張り付かないよう、コメント数と参加者数は非線形にしています。
